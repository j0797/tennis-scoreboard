К классам и файлам конфигурации добавлены подробные комментарии. Там же есть ссылки на файлы, объясняющие некоторые особо значимые темы. Сами файлы с заметками находятся в одном пакете с классами, к которым относится тема заметки.

```
В `TODO`-комментариях️ описаны критически важные замечания, а также места нарушения ТЗ.
```

Читать стоит в таком порядке:

- В файле `Functional-overview.md` описан функциональный обзор приложения.

- В файле `CONCISE_ROADMAP.md` описан план работы над исправлениями.

- В файле `Pluses.md` описаны наиболее значимые плюсы. (можно читать в любое время)

- В файле `Conclusion.md` находится заключение. (можно читать в любое время)
